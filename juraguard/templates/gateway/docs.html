Client field guide

Connect once.
Search everything.

OAuth is preferred for every AI client. Add {{ mcp_url }} without a token or authorization header, then approve access in your browser.

Supported clients

ClaudeCursorVS Code / CopilotCodex CLIOpenCodeGemini CLIWindsurfGeneric HTTP

01

Claude Code & Desktop

Claude Code: add the server, run /mcp, and authenticate juraguard. Verify with claude mcp get juraguard.

claude mcp add --transport http juraguard {{ mcp_url }}

Claude Desktop: open Customize → Connectors → Add custom connector, enter {{ mcp_url }}, then complete browser approval.

02

Cursor

Run the installer and choose HTTP, name juraguard, and URL {{ mcp_url }}. Then run agent mcp login juraguard and agent mcp list.

agent mcp add

03

VS Code / GitHub Copilot

Run the installer. Connect to open browser approval, then verify with MCP: List Servers.

code --add-mcp '{"name":"juraguard","type":"http","url":"{{ mcp_url }}"}'

04

Codex CLI

Run both commands, then verify with codex mcp list.

codex mcp add juraguard --url {{ mcp_url }}
codex mcp login juraguard

05

OpenCode

Run one command. OpenCode starts OAuth automatically when you first use Juraguard. To connect immediately, run opencode mcp auth juraguard.

opencode mcp add juraguard --url {{ mcp_url }}

06

Gemini CLI

Run the installer. Start Gemini, run /mcp auth juraguard, then verify with gemini mcp list.

gemini mcp add --transport http juraguard {{ mcp_url }}

07

Windsurf

Windsurf has no supported installer command. Open Windsurf Settings → Tools → Add Server, enter {{ mcp_url }}, complete browser approval, then refresh the MCP server list.

08

Generic Streamable HTTP

Use MCP OAuth when the client supports it. Otherwise generate a manual token from the dashboard and keep it outside version control.

curl {{ mcp_url }} \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

Source & support

The public source mirror and issue tracker are coming soon. GitLab remains the authoritative development repository. Juraguard supports remote Streamable HTTP MCP, with no stdio, WebSocket, or SSE GET transport.
